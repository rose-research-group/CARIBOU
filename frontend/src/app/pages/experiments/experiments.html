Where do I get this token, and where is it stored?
Using a shared server

If you have terminal access under the CARIBOU service account, run caribou config get-control-token. Otherwise, request the token from the server operator through an approved secure channel.

Running CARIBOU yourself

caribou serve displays the token during startup. If none exists, it generates one and saves it in CARIBOU's protected environment file; later serve runs reuse it.

Browser handling

The token is stored in this tab's session storage and attached only as an X-Caribou-Control-Token header on /api/control/* requests. It survives reloads in this tab, is normally cleared when the tab closes, and can be removed immediately with Clear token.
